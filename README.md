# sealpix

本人確認書類などの写真から、氏名や番号などの見られたくない部分を、利用者のブラウザの中で暗号化してから送るための部品です。どの Web システムにも組み込めることを目指しています。

> **開発中です。まだリリースしていません。** 仕様は変わることがあります。
>
> **このコードは、第三者によるセキュリティの検査を受けていません。**

## しくみ（設計）

- 利用者のブラウザで、写真の隠す範囲をノイズで塗りつぶし、元の部分を公開鍵で暗号化します。元の部分は、暗号化される前にブラウザの外へ出ません。
- サービスの提供者は、ノイズ入り画像と暗号化ファイルの2つを、自社の保存先に保存します。
- 照合のときだけ、提供者が自社で立てた復号サーバーが秘密鍵で復号し、権限のある担当者が元の部分を重ねて確認します。
- 秘密鍵は提供者の復号サーバーの中にだけ置きます。共用のサービスは使いません。

## 方式（設計）

| 方式       | 内容                                                                                             | 予定の版   |
| ---------- | ------------------------------------------------------------------------------------------------ | ---------- |
| 全部暗号化 | 画像全体を暗号化します。当てはまる位置の型がない書類もこの方式になります                         | 初版       |
| 型方式     | 書類の種類と面ごとの「位置の型」と、提供者ごとの「隠し方の設定」に従って、決まった項目を隠します | 初版       |
| 自分で選ぶ | 画像の上に範囲を描いて選びます                                                                   | 初版のあと |

## 暗号化ファイルの形式

JWE（RFC 7516）の Flattened JSON Serialization です。JOSE に対応したライブラリなら、どの言語でも復号できます。

- 鍵の包み方: `RSA-OAEP-256`（RSA 3072 ビット以上）
- 中身の暗号化: `A256GCM`
- `kid`: 公開鍵の JWK Thumbprint（RFC 7638）
- protected ヘッダーの `sealpix` に、形式の版、方式、画像の大きさ、隠した範囲の座標を入れます。protected ヘッダーは暗号化しませんが、書き換えると復号できなくなります。
- 中身は、範囲ごとに、範囲を囲む四角形とその部分の PNG 画像です。

## 守れること・守れないこと（設計上の目標）

まだ実装していない部分を含みます。

守れること:

- 保存先が盗まれても、秘密鍵がなければ隠した部分は読めません。
- 保存されるノイズ入り画像は、検査サービスで必ず隠れた状態にします。
- 誰がいつ復号したかが記録に残ります。

守れないこと:

- 利用者が、暗号化する中身を別の画像にすり替えること。サーバーは元の写真を持たないので、中身が本物かは確かめられません。照合のときに担当者が目で確かめてください。
- 復号サーバーの秘密鍵を盗まれること。
- 復元した画像を、提供者のシステムが保存したり、画面を撮影されたりすること。
- 隠す範囲の外に写った情報。位置の型が書類に合っていなければ漏れます。

担当者ごとの権限、復元した画像の扱い、秘密鍵の保管と控えは、提供者の責任です。秘密鍵をなくすと、それまでの暗号化ファイルは二度と復号できません。
