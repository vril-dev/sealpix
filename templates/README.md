# テンプレート

書類の種類と面ごとに、各項目の位置を定義したファイルです。座標は、書類の傾きを補正して 856 × 540 ピクセル（ID-1 サイズのカードの縦横比）に揃えた画像での値です。

| ファイル                       | 書類             | 項目                                                                                                                             |
| ------------------------------ | ---------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `jp-driver-license-front.json` | 運転免許証（表） | 氏名、生年月日、住所、交付年月日・照会番号、有効期限、免許の条件等、免許証番号、免許の取得年月日、免許の種類、顔写真、公安委員会 |
| `jp-driver-license-back.json`  | 運転免許証（裏） | 裏面全体                                                                                                                         |

運転免許証の位置は、公開されている見本の券面から測ったものです。実物の券面での確認はまだ行っていません。位置のずれは、ポリシーの `padding` で広げて吸収してください。

## 形式

```json
{
  "id": "jp-driver-license-front",
  "version": 1,
  "label": "運転免許証（表）",
  "card": { "width": 856, "height": 540 },
  "fields": [{ "id": "name", "label": "氏名", "rect": [100, 34, 437, 40] }]
}
```

- `rect` は、項目の左上の x 座標、y 座標、幅、高さです。
- テンプレートは、[テンプレートエディター](../packages/browser/README.md#sealpix-template-editor)で作成・編集できます。
- 位置を直したときは `version` を上げてください。暗号化データには、暗号化したときのテンプレートの ID とバージョンが記録されます。

## ポリシー

どの書類を受け付け、どの項目を暗号化するかは、導入するサービスごとにポリシーで決めます。例は [`examples/policy.json`](../examples/policy.json) にあります。

| `mode`     | 暗号化する範囲                      |
| ---------- | ----------------------------------- |
| `hide`     | `fields` に挙げた項目               |
| `show`     | `fields` に挙げた項目以外のすべて   |
| `hide-all` | 書類全体（`fields` は指定しません） |

`padding` は、位置のずれを見込んで暗号化する範囲を広げる幅（ピクセル）です。`show` では、見せる項目の範囲を同じ幅だけ狭めます。
